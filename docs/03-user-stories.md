# User Stories

## Autenticação

- US001 - Como cliente, quero criar uma conta para realizar compras na loja.

- US002 - Como cliente, quero fazer login para acessar minha conta.

- US003 - Como cliente, quero recuperar minha senha para voltar a acessar minha conta caso a esqueça.

---

## Perfil

- US004 - Como cliente, quero atualizar meus dados pessoais para manter meu cadastro correto.

- US005 - Como cliente, quero cadastrar mais de um endereço para escolher onde receber meus pedidos.

---

## Produtos

- US006 - Como cliente, quero visualizar todos os produtos para escolher o que comprar.

- US007 - Como cliente, quero pesquisar produtos para encontrá-los rapidamente.

- US008 - Como cliente, quero filtrar produtos por categoria para facilitar minha busca.

- US009 - Como cliente, quero visualizar os detalhes de um produto antes da compra.

---

## Carrinho

- US010 - Como cliente, quero adicionar produtos ao carrinho para comprá-los posteriormente.

- US011 - Como cliente, quero alterar a quantidade de produtos no carrinho.

- US012 - Como cliente, quero remover produtos do carrinho caso mude de ideia.

---

## Pedidos

- US013 - Como cliente, quero finalizar uma compra de forma simples e segura.

- US014 - Como cliente, quero acompanhar meus pedidos após a compra.

- US015 - Como cliente, quero visualizar meu histórico de pedidos.

---

## Favoritos

- US016 - Como cliente, quero favoritar produtos para encontrá-los facilmente no futuro.

---

## Administração

- US017 - Como administrador, quero cadastrar produtos para disponibilizá-los na loja.

- US018 - Como administrador, quero editar produtos para manter as informações atualizadas.

- US019 - Como administrador, quero controlar o estoque dos produtos.

- US020 - Como administrador, quero visualizar todos os pedidos realizados.
